## 结论

把「推进任务的 LLM 会话」归纳为一个**无副作用**的 λ-演算核心，用于统一描述任务拆解、子会话递归、选路、校验与重试。只描述计算，不描述 IO。

- 会话 = 纯函数 `PB : Nat → Cin → Maybe Cout`
- 递归不求不动点，用 **level 当 fuel 的结构递归**，终止性由类型保证
- 副作用一律外移到驱动层，项语言里不存在 IO
- 非确定性只有两个入口常数：`choose`（选项判定）与 `gen`（计算判定）

## 类型与项语言

```text
κ ::= Det | NDet              -- 子类型规则: Det τ ≤ NDet τ
τ ::= κ σ
σ ::= σ → σ | σ × σ | List σ | Maybe σ | Nat | Task | Result
```

```text
e ::= x | λx. e | e₁ e₂                 -- 抽象 / 应用
    | ⟨e₁, e₂⟩ | fst | snd              -- 积：合并子结果
    | if e₁ then e₂ else e₃             -- 分支
    | fold e₁ e₂ e₃                     -- 替代 for
    | just e | nothing | orElse e₁ e₂   -- 失败用 Maybe 表达，没有 throw
    | choose | gen                      -- 仅有的两个非确定源
```

除 `choose` / `gen` 外，所有组合子保 `Det`；非确定性只能从这两个口子进入，且被类型标注。

## 递归与通用会话形态

```text
PB zero     = λ_. nothing               -- 燃尽即失败，天然终止
PB (succ n) = λx. body                  -- body 内只允许调用 PB n

session (succ n) task =
    let subs = gen (decompose task)
    in fold (λacc t. case session n t of
                 nothing → acc
                 just r  → r :: acc) [] subs
    |> λrs -> if validate rs then just (merge rs)
              else orElse (session n (repair task)) nothing
```

## 草图映射

- `PB（级别，输入约束类型）→ 输出约束类型` → `PB : Nat → Cin → Maybe Cout`
- 「级别」→ `Nat` 燃料；「确定型/非确定型」→ `Det`/`NDet`
- 「LLM 选项判定」→ `choose`；「LLM 计算判定」→ `gen`
- `PB1; PB2` → 函数复合；`for` → `fold`；`if` → `if`；`return` → `just`；`catch` → `orElse`/`Maybe`

## 边界（有意排除）

| 能力 | 处理方式 |
|---|---|
| 副作用（发消息、写文件） | 驱动层拿到 `just result` 之后才执行 |
| 挂起/恢复（等人确认） | 表示为分次调用，人的输入作为下一次调用的 `Cin` |
| 环境非确定性（工具漂移） | 不建模，进入 `PB` 时已是确定值 |
| 并行 fork/join | 可扩 `join` 组合子；当前最小语法用 `fold` 覆盖顺序场景 |
| 上下文投影 | `Cin` 是父上下文的投影/摘要，由驱动层调用前计算 |
